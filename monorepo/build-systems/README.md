# Monorepo Build-System Specializations

Build-system documents are thin mappings from [monorepo core](../core/README.md) to version-matched official behavior. They do not redefine package ownership, dependency direction, client/server layers, or scaffolding safety.

## Supported Specializations

| Build system | Status | Documentation |
| --- | --- | --- |
| Turborepo | Supported | [Turborepo](./turborepo/README.md) |

An unlisted build system is not rejected. Apply the core contract, inspect the target repository, retrieve current authoritative resources, show the derived role-to-tool mapping for approval, and verify it with the selected tool.
